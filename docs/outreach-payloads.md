# Outreach payloads

These are research-backed drafts for one-to-one outreach. Each uses one public friction point and one concrete workflow change. Human approval is required before sending.

## 1. Arasan Real Estate

Observed friction:
A public business listing uses a generic “Send Enquiry” flow for real-estate/construction services, rather than a property-specific qualification flow. The form asks for product/service, quantity, requirement details, service location, name, mobile and email.

4-frame demo:
1. Buyer opens a property listing.
2. Intake captures property type, preferred area, budget, purpose and site-visit preference.
3. Automation classifies intent and priority, then prepares the owner notification.
4. Owner dashboard shows the lead, timestamp, priority and follow-up task.

Message:

I reviewed the public enquiry flow for Arasan Real Estate. It currently treats a property enquiry much like a generic service quote.

I built a small workflow that would turn each enquiry into a structured lead: property type, area, budget, intent, visit preference, priority and a follow-up task.

I can remove that repetitive qualification step from your process in 7–14 days. Fixed price. You approve the final system before it goes live.
