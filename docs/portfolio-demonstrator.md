# Portfolio workflow demonstrator

## Before

A visitor clicks an email link and the owner manually:
1. reads the message;
2. decides what it is about;
3. decides how urgent it is;
4. replies;
5. remembers to follow up.

## After

The public form sends one structured request:

Visitor
→ API intake
→ validation / honeypot / rate limit
→ intent + urgency + priority classification
→ persistent lead record
→ owner notification
→ visitor acknowledgement
→ follow-up task with due date
→ owner dashboard

## Evidence captured by the system

Every accepted submission stores:
- received timestamp
- processing timestamp
- processing duration
- classification source
- intent
- urgency
- priority
- email delivery status
- follow-up task status
